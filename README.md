# 🚀 GigFlex – Freelance Marketplace Portal

A full-stack freelance marketplace platform that connects clients and freelancers through a secure and role-based web application.

## 🌟 Project Overview

GigFlex is a full-stack web application designed to provide a platform where **clients can post/manage freelance opportunities** and **freelancers can explore and apply for suitable projects**.

The application provides separate dashboards for clients and freelancers with secure authentication and role-based access.

---

## ✨ Features

### 👤 User Management
- User registration and login
- Client and Freelancer roles
- Role-based dashboard access
- Secure authentication

### 💼 Client Features
- Client dashboard
- Manage freelance projects
- View project-related information
- Manage freelancer interactions

### 👨‍💻 Freelancer Features
- Freelancer dashboard
- Explore available projects
- Apply for suitable opportunities
- Manage application-related information

### 🔐 Security
- JWT-based authentication
- Protected routes
- Role-based authorization
- Secure password handling
- Authentication middleware

### ⚡ Backend
- RESTful APIs
- Node.js server
- Express.js framework
- MongoDB database
- Mongoose data modeling
